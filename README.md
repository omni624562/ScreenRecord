# 螢幕錄影（ScreenRecorder）

Windows 11 螢幕錄影工具：**原速錄影並完整保留，停止後再選倍率製作加速版**（可對同一支錄影重複製作不同倍率，高倍率即是縮時影片）。

- 全部以 Rust 撰寫的單一執行檔：錄影、轉檔、剪輯、系統匣與操作視窗（egui）都在同一個程式裡，不需要 WebView2 或瀏覽器
- 擷取與編碼交給 FFmpeg：優先 `ddagrab`（Desktop Duplication，GPU 擷取），不支援或失敗時自動退回 `gdigrab`
- 輸出 H.264 MP4（yuv420p、BT.709）

目前版本：**3.2.6**　各版本的變更見 [CHANGELOG.md](CHANGELOG.md)（版本號顯示在操作視窗的標題列；在程式裡可從「設定 → 關於」或系統匣選單「關於」查看這一版與所有版本的更新說明）。

## 功能

| 項目 | 說明 |
| --- | --- |
| 擷取範圍 | 單一螢幕（DXGI 列舉；可在預覽上拖曳框選只錄其中一部分，按「整個螢幕」取消）、所有螢幕（整個延伸桌面拼成一個畫面），或自訂範圍：按「在螢幕上框選…」直接在螢幕上框（和框選截圖一樣，可調整後按 Enter）、在預覽圖上拖曳框選（可跨螢幕；框好後可拖曳移動、拉邊角調整大小），或展開「精確數值」用 − ＋ 調整 X、Y、寬、高 |
| 聲音 | 可選擇錄「系統聲音」（電腦播放的聲音）與「麥克風」（可選裝置），兩者可同時錄並混音；AAC 48 kHz 立體聲；預設兩者都錄 |
| 錄影設定 | FPS（15/24/30/60 或自訂 1–60）、解析度縮放 100/75/50/25%、是否錄進游標、最長錄影時間（0 = 不限）；全部集中在「設定」視窗（錄影、聲音、儲存位置、錄完處理、快速鍵、進階、關於），主畫面下方只顯示摘要，點一下開到對應分頁 |
| 錄影控制 | 開始 / 暫停 / 繼續 / 停止；暫停採分段錄製，停止後以 concat（stream copy）合併成單一檔案 |
| 截圖 | 主畫面「框選截圖」（`Ctrl+Alt+A`；放開滑鼠後可以調整範圍，再選完成、編輯、複製、釘在桌面或整個螢幕）或「整個範圍」（`Ctrl+Alt+S`，擷取與錄影相同的範圍：單一螢幕 / 所有螢幕 / 自訂範圍），也可從系統匣選單；存成原尺寸 PNG 並複製到剪貼簿（可直接貼到 LINE、Word、信件）；操作視窗擋到範圍時先縮小再截。延遲截圖在畫面上倒數（Esc 取消）。主畫面「全部截圖」以縮圖格瀏覽（可檢視、顯示、改名、勾選多張刪除；Ctrl＋點一下多選、Shift＋點一下選一段、Ctrl+A 全選本頁），與錄影分開 |
| 框選截圖 | `Ctrl+Alt+A` 或系統匣「截圖 → 框選範圍或視窗」：畫面先凍結並變暗，拖曳框選範圍，或點一下擷取游標下的視窗（Esc / 右鍵取消）；從凍結的畫面裁切，截到的就是當下看到的樣子。系統匣另有「全螢幕」（各螢幕 / 所有螢幕）、「固定範圍」（主畫面的錄影範圍）、「重複上次框選」。錄影也能這樣選：系統匣「錄製其他範圍 → 框選範圍或視窗…」框好就開始錄影，另有「全螢幕」與「重複上次框選」。錄自訂範圍時，螢幕上的範圍外圍會一直顯示細框（錄影中紅色、暫停橘色；不會錄進影片，滑鼠可穿過），左上方的小控制列顯示已錄時間，可暫停 / 繼續、停止；拖曳控制列可移動範圍（大小不變，錄影中移動會換一個分段，中間約 0.5～1 秒沒錄到；主畫面的範圍也跟著記住新位置）。控制列右邊的「‹」縮成只有狀態點與停止的小控制列（「›」展開，會記住）；設定 → 錄影 →「錄影控制列」也可以選不顯示（倒數完就隱藏，用快速鍵或系統匣停止）。錄整個螢幕時控制列在螢幕上方中間，可以拖到別的地方（例如另一個螢幕），會記住位置，雙擊放回上方中間 |
| 全域快速鍵 | `Ctrl+Alt+R` 開始 / 停止（倒數中為取消）、`Ctrl+Alt+P` 暫停 / 繼續、`Ctrl+Alt+S` 截圖、`Ctrl+Alt+A` 框選截圖、`Ctrl+Alt+M` 錄影中加標記、`Ctrl+Alt+D` 螢幕畫筆、`Ctrl+Alt+B` 回溯錄影（開始 / 存下），在任何程式中都能用（需系統匣常駐）；可在「設定 → 快速鍵」點按鍵後按下新的組合鍵更換（要包含 Ctrl 或 Alt），也可個別停用或還原預設 |
| 倒數與自動縮小 | 開始前倒數 0 / 3 / 5 / 10 秒（操作視窗在錄影範圍外時只在按鈕上倒數，不擋畫面）；開始擷取時自動縮小擋到錄影範圍的操作視窗、停止後還原，避免錄到它（視窗在其他螢幕上就不縮小） |
| 磁碟空間 | 剩餘不到 1 GB 不開始；錄影中低於 2 GB 提醒、低於 512 MB 自動停止並儲存 |
| 正常收尾 | 停止、暫停、結束程式時都對 FFmpeg 送出 `q`，逾時（10 秒）才強制終止 |
| 搜尋說過的話 | 「全部錄影」的搜尋也找影片旁邊的字幕檔（同名的 `.srt`，自動字幕或錄完自動處理產生），符合的錄影底下列出最多 3 句（時間與那一句，搜尋的字標示出來），點一下在檢視器從那一句開始播放 |
| 直式影片（9:16） | 剪輯視窗「畫面裁切」分頁選「放在中間」（整個畫面放在 1080×1920 或 720×1280 的直式畫面中間，上下是放大、模糊、稍暗的同一個畫面，什麼都不會被裁掉）或「跟著游標」（裁出 9:16 的一塊，像攝影機一樣跟著錄影時記下的游標左右移動；游標在鏡頭中間一半的範圍內移動時鏡頭不動，出了範圍才用彈簧平順地移過去；沒有游標位置時跟著點擊；太大時縮成 1080×1920）。預覽時看得到裁切的框。跟著游標用 `sendcmd` 依原影片的時間移動 `crop`；直式影片時不能同時用跟著點擊放大、背景與圓角 |
| 平滑、放大的游標 | 錄影時記下游標的位置（約每 30 毫秒，存在 `markers/`）。剪輯視窗「畫面裁切」分頁打開「換成大游標、平順移動」並選 1.5×／2×／3×：輸出時把游標畫成大的白色箭頭，位置像彈簧一樣平順地跟過去（臨界阻尼，約 0.1 秒追上；手抖、急停、跳動都變得流暢），畫在標註底下，預覽也看得到。FFmpeg 用 `sendcmd` 依原影片的時間移動 `overlay`。錄影前到「設定 → 錄影」關掉「滑鼠游標：錄進影片」，影片裡才不會同時有原本的小游標 |
| 回溯錄影 | 錄影面板右上角「回溯錄影」選保留最近 30 秒～10 分鐘後開始（或按 `Ctrl+Alt+B`）：在背景一直錄、只留最近那一段，發生想留下的事時按「存下最近 N 分鐘」（或再按一次 `Ctrl+Alt+B`、系統匣、螢幕上控制列的存下按鈕），存成 `Replay_<時間>.mp4`，可以存好幾次。FFmpeg 用 segment 輸出每 10 秒換一個暫存檔（每秒寫入），定期刪掉太舊的，存下時把最近幾個接起來（不重新壓縮，連正在寫的也包含）；停止時暫存檔全部刪掉（還有沒存下的內容時，主畫面、系統匣、控制列、快速鍵的停止都會先問要不要存下）。用目前的範圍與聲音設定，不倒數、不縮小視窗，不能暫停或加標記 |
| 只錄某個程式的聲音 | 「設定 → 聲音 → 系統聲音來源」選開啟中的程式（列出有視窗的程式，例如 `chrome.exe`、`Teams.exe`）：系統聲音只錄那個程式和它開的子程序播放的聲音（Windows 的 process loopback），其他程式的通知音、音樂不會錄進去；開始錄影時程式沒開或 Windows 版本太舊（不支援）時改錄全部系統聲音，事件紀錄寫上原因。設定組合也會記住 |
| 聲音分軌 | 「設定 → 聲音 → 分軌」：系統聲音與麥克風都錄時，影片多兩條音軌（第一條仍是混在一起的「混音」，一般播放器照常播放；另兩條是「系統聲音」「麥克風」）。剪輯時可以「分別調整系統聲音與麥克風」（0～200%），降噪只處理麥克風；自動字幕只聽麥克風那條。聲音管線送出 6 個聲道，FFmpeg 拆成三條 AAC 音軌 |
| 錄完自動處理 | 「設定 → 錄完處理」：錄影存好後依序自動剪掉沒動靜的片段（另存 `_cut.mp4` 並存剪輯設定，可在剪輯視窗再改）、產生字幕（影片旁邊存 `.srt`；第一次先下載語音模型）、壓縮到指定大小以內（另存壓縮版；有剪輯版時字幕與壓縮用剪輯版）。一次一支，等手動的轉檔結束才做；開始新的錄影時先暫停、錄完再繼續；錄影面板用一張卡片顯示第幾步與進度、可取消，完成後可直接播放處理好的版本 |
| 排程錄影 | 錄影面板右上角「排程」：選今天、明天或其他日期的時間（或幾分鐘後）開始，可設定錄幾分鐘後自動停止；到時間用目前的錄影設定直接開始（不倒數）。錄影面板顯示還有多久開始、可取消，系統匣也能取消。排程存在設定裡，重新開啟程式後繼續等（程式要開著，收到系統匣也可以；結束程式前會提醒）；等待期間與錄影中電腦不會因為閒置而睡眠 |
| 講稿小視窗 | 錄影面板右上角「講稿」：浮在最上層的小視窗，設成不會被錄進影片或截圖（Windows 10 2004 以後）。「編輯」貼上講稿（存在 `%LOCALAPPDATA%\ScreenRecorder\notes.txt`）；「提詞」用深色底大字往上捲，讀的位置固定在上方三分之一，讀過的變暗；空白鍵播放 / 暫停、Home 回到開頭、↑↓ 調速度、滾輪手動調整；「⋯」可調字級、不透明度，預設開始錄影時自動捲動、暫停或停止時停下。操作視窗收到系統匣時一起收起來 |
| 設定組合 | 把錄影範圍、FPS、縮放、游標、聲音與麥克風、儲存位置、倒數、錄影時的效果、攝影機存成有名字的組合（例如「教學影片」「線上會議」）；主畫面下方「設定」左邊的按鈕切換、存成組合（同名就是更新）、重新命名、刪除，系統匣「設定組合」也能切換（勾選的是目前的設定）。存在 `settings.json` 的 `presets`，最多 20 組 |
| 救回中斷的錄影 | 錄影中程式當掉、停電或被強制關掉時，分段已每秒寫入硬碟；下次開啟會列出沒有存好的錄影，可救回（合併成 `Rec_開始時間.mp4`）或刪除 |
| 即時資訊 | 已錄時間、影片長度、檔案大小、實際 fps；電腦跟不上即時錄影時會提示 |
| 製作加速版 | 可縮小尺寸（寬 1920 / 1280）、顯示預估大小、已有同倍率時提醒；可設大小上限（10 / 25 / 50 / 100 MB，自動算位元率）；「⋯」選單另有「壓縮（傳 LINE / Email）」：原速壓縮到大小上限以內（檔名例如 `操作示範_25MB以內.mp4`，原片夠小時直接說明）；可按「變更…」選存檔位置；指定倍率（1.5/2/4/8/16× 或自訂 1.1–1000×）或指定長度（例如 1:00，自動算倍率），顯示「原片 → 加速後」長度與匯出進度，可取消；可保留聲音（變速不變調） |
| 製作 GIF / WebP 動圖 | 可選寬度（320–1280 px）與每秒張數，可同時加速；GIF 短片用整段共用調色盤（檔案小），長片改用每張畫面各自的調色盤（記憶體固定）；WebP 動圖檔案約為 GIF 的 1/6、顏色更好（瀏覽器、Slack、Discord 都能看） |
| 剪輯影片 | 剪掉頭尾、刪除中間多段、裁切畫面範圍（在影片上拖曳框選）、加上標註（文字、表情符號、箭頭、框線、螢光筆、畫筆、步驟編號、馬賽克、模糊、聚光燈、圖片 / Logo）、聲音處理（不要聲音、降噪、音量平衡）、局部加速（選一段 2–16 倍速）、自動剪掉沒動靜的片段（畫面不動又沒聲音超過 2 秒）、跟著點擊放大（用錄影時記下的點擊），另存成 `*_cut.mp4`，原檔不變；剪輯版可再拿去製作加速版 |
| 截圖編輯 | 檢視器或「全部截圖」按「編輯」：標註（文字、表情符號、箭頭、方框、圓框、螢光筆、畫筆、步驟編號）、馬賽克 / 模糊遮個資（也可用文字辨識自動找出 Email、電話、身分證字號、卡號）、放大鏡、裁切、向左 / 右旋轉、外框、陰影、圓角、漸層背景、縮小輸出；存成 `Shot_…_編輯.png`（原圖保留，之後可再改）並複製到剪貼簿，或按「儲存」旁的箭頭「另存新檔…」選位置與 PNG / JPG；裁切後在其他分頁只顯示保留的部分（上方可「調整裁切」或「還原整張」）；可縮放與捲動（Ctrl+滾輪；圖比畫面大時在空白處按住左鍵拖曳、或按住空白鍵拖曳移動，長截圖用「符合寬度」）；工具快速鍵（T、E、A、R…）、方向鍵微調、Ctrl+D 複製一份、Ctrl+C / Ctrl+V 複製貼上；復原 / 重做。可設定截圖後直接開啟編輯，或點截圖後的小縮圖編輯 |
| 釘在桌面、文字辨識 | 把截圖變成浮在最上層的小視窗（拖曳移動、滾輪縮放、點兩下關閉）；用 Windows 內建的文字辨識把圖裡的文字轉成可以複製的文字 |
| 延遲截圖、擷取畫面 | 「截圖」按鈕按右鍵或系統匣「延遲框選」：3 / 5 / 10 秒後再框選；剪輯視窗、檢視器「擷取這一格」把影片目前的畫面存成截圖 |
| 點擊、按鍵、攝影機 | 錄影時可顯示滑鼠點擊的波紋與按下的快速鍵（一般打字不顯示），也可在螢幕上放攝影機小視窗（圓形或方形；錄影前就會顯示，可拖曳移動、調整大小，並記住位置與大小）；都會錄進影片 |
| 只錄某個視窗 | 「自訂範圍 → 選擇視窗」或系統匣框選時點一下視窗：錄影範圍跟著視窗移動。打開「只錄視窗內容」時改用 Windows Graphics Capture（FFmpeg 的 `gfxcapture`）直接擷取那個視窗：被其他視窗擋住、移到哪裡都錄得到，畫面上的其他東西（攝影機小視窗、點擊與按鍵效果、螢幕畫筆）不會錄進去；開始時就失敗或錄到一半中斷（例如視窗關掉）時自動改回跟著視窗的範圍 |
| 錄影中加標記 | 錄影時按 `Ctrl+Alt+M`、外框控制列的旗子或主畫面「標記」加標記（記在 `%LOCALAPPDATA%\ScreenRecorder\markers\`）；剪輯時時間軸底下顯示橘色旗子，點一下或按 Shift+M / Ctrl+Shift+M 跳到下一個 / 上一個；剪輯視窗按 M 或「＋ 加標記」新增，按兩下旗子改名（輸出時當作章節名稱）、右鍵刪除。存檔時標記也寫成影片章節（加速版、剪輯版跟著換算），檢視器可跳章節，「更多」選單可複製成 YouTube 章節 |
| 長截圖 | 框選要捲動的內容，自動往下捲並接成一張長圖（處理捲軸、固定的標題列與頁尾、不動的側欄；Esc 停止） |
| 步驟截圖 | 每點一下滑鼠截一張並標出點的位置；截圖時畫面下方有小工具列（完成、取消），完成後先整理步驟（刪除、調整順序、改標題），再做成一個 HTML 教學文件（圖片包在檔案裡，可修改文字、列印成 PDF） |

剪輯視窗：時間軸上有縮圖，拖曳兩端的黃色把手剪掉頭尾，在時間軸上拖過一段可選取並刪除（刪掉的片段點 × 還原），「預覽結果」只播放保留的部分。在時間軸上轉滾輪放大 / 縮小（Shift 左右移動），在影片上轉滾輪逐張前後移動，拖曳上方的黃色橫條整段移動保留範圍。右側「標註」分頁選工具後在影片上點一下或拖曳放置；每個標註在時間軸下方的標註軌有一條，拖曳可調整出現時間（落在刪除片段裡的會提醒），步驟編號依出現時間自動排序，可連續點擊放置；馬賽克、模糊可選方形、圓角、橢圓，也可以改成框外模糊（框內清楚）。標註可以旋轉：拖曳選取框上方的圓點，或在右側調整「角度」。剪輯版之後還能再修改：再次開啟剪輯版時會從原始影片載入當時的剪輯與標註（記在 `%LOCALAPPDATA%\ScreenRecorder\edits\`），儲存時取代那個剪輯版；原始影片被刪除後就只能在剪輯版上繼續剪。時間軸上方有時間尺規（點一下或拖曳移動播放位置）；在縮圖上拖曳是移動播放位置，按住 Shift 拖曳（或打開「選取範圍」）才是選取；「在這裡分割（S）」把影片切開，點一段就能選取、刪除或加速。播放時預設跳過刪掉的片段。右側分頁：修剪｜畫面｜標註｜字幕｜聲音。輸出失敗或取消時可以「回到剪輯」；剪輯中每 10 秒自動存草稿，下次開啟同一支影片可以繼續。快速鍵（按「快速鍵」按鈕看全部）：空白鍵 播放 / 暫停、← / → 上一格 / 下一格（加 Shift 為一秒）、S 分割、M 加標記、Shift+M / Ctrl+Shift+M 下一個 / 上一個標記、I 設為開頭、O 設為結尾、Delete 刪除最後選取的片段或標註、Ctrl+S 儲存、Ctrl+Z / Ctrl+Y 復原 / 重做、Esc 取消選取（沒有選取時關閉剪輯視窗，有還沒儲存的修改會問「儲存後關閉／不儲存／取消」）。

## 使用

### 系統匣常駐

程式啟動後常駐在工作列右下角的系統匣（Windows 11 新程式預設在 `^` 收合區，可拖到工作列上，或在「設定 → 個人化 → 工作列 → 其他系統匣圖示」開啟）。

- **左鍵點圖示**：開啟操作視窗
- **右鍵選單**：開始錄影（沿用上次設定）、錄製指定螢幕 / 所有螢幕、暫停 / 繼續、停止並儲存、加標記、截圖（框選範圍或視窗 / 延遲框選 / 全螢幕 / 固定範圍 / 重複上次框選 / 編輯上次截圖）、切換系統聲音 / 麥克風、開啟儲存資料夾、播放最近的錄影、開機時自動啟動、結束
- 圖示顏色代表狀態：深色 = 待命、紅色圓環 = 倒數中、紅色 = 錄影中、琥珀色 = 已暫停；滑鼠停在圖示上會顯示已錄時間
- 錄影儲存後會跳出通知，點通知開啟操作視窗
- 關閉操作視窗不會結束程式（仍常駐在系統匣）；要結束請用系統匣選單的「結束」
- 設定存在 `%LOCALAPPDATA%\ScreenRecorder\settings.json`，記錄檔 `ScreenRecorder.log` 也在同一處

### 執行編譯好的版本

從 [Releases](https://github.com/omni624562/ScreenRecord/releases/latest) 下載 `ScreenRecorder.zip`（解壓縮後使用）或 `ScreenRecorder.exe`（單一執行檔）。

```
ScreenRecorder.exe
ffmpeg.exe          ← 放在同一個資料夾
```

找不到 `ffmpeg.exe` 時，介面上方會出現提示，按「自動下載」即可：從 [gyan.dev](https://www.gyan.dev/ffmpeg/builds/) 下載固定版本 FFmpeg 9.0.2 essentials（約 110 MB，失敗時改用 GitHub 上的同一檔案），比對程式內建的 SHA-256（不是從下載網站取得，檔案遭竄改也會被擋下）後，用 Windows 內建的 `System32\tar.exe` 解出 `ffmpeg.exe`，放到 exe 旁邊（沒有寫入權限時放 `%LOCALAPPDATA%\ScreenRecorder`），完成後自動偵測，不用重開程式。下載可取消，不會留下未完成的檔案。也可以按「手動下載」自行下載後放好，再按「重新偵測」。  
搜尋順序：`exe 所在資料夾\ffmpeg.exe` → `ffmpeg\bin\ffmpeg.exe` → `bin\ffmpeg.exe` → `%LOCALAPPDATA%\ScreenRecorder\ffmpeg.exe` → `PATH`。

自動字幕需要有 whisper（語音辨識）的 FFmpeg，essentials 沒有。第一次產生字幕時，程式會另外下載同一版的 FFmpeg 9.0.2 full（約 258 MB，從 GitHub 下載，失敗時改用 gyan.dev，一樣比對內建的 SHA-256），和語音模型一起放在 `%LOCALAPPDATA%\ScreenRecorder\whisper`，只用來辨識語音；錄影、轉檔仍用原本的 FFmpeg。目前用的 FFmpeg 已經有 whisper 時不會下載。

從系統匣選單「結束」會先把錄影正常收尾並合併再結束。程式不顯示主控台視窗，訊息寫在記錄檔 `%LOCALAPPDATA%\ScreenRecorder\ScreenRecorder.log`。

參數：`--port <n>`（單一執行個體控制用的本機連接埠，預設 47391，被占用時往後找）、`--no-open`（不自動開操作視窗）、`--tray`（只常駐系統匣，開機自動啟動時使用；系統匣還沒準備好時在背景重試、不開視窗，操作視窗等第一次開啟時才建立；開機自動啟動指向別的位置的程式時，例如舊版留在原本的資料夾，啟動時會改成目前這個程式）、`--no-tray`（開發測試用：不建立系統匣、不檢查是否已在執行，可與正式程式並存）。同時只會有一個執行個體，重複啟動會直接開啟現有的操作視窗。

### 開發

只需要 [Rust](https://rustup.rs/)：

```bash
cargo run -p screenrecorder-ui
```

```bash
cargo test --workspace
```

```bash
cargo clippy --workspace --all-targets
cargo fmt --all
```

要與已安裝的正式版並存時加上 `-- --no-tray`。`core` 的單元測試在 Linux 上也能跑；`core/src/e2e_tests.rs` 用真的 FFmpeg 跑完整流程（用錄影的參數錄分段、停止合併與章節、當掉後救回、加速版、GIF、WebP、剪輯的各種效果、合併、找出沒動靜的片段、播放器解碼），FFmpeg 用環境變數 `SCREENRECORDER_TEST_FFMPEG` 指定，否則用 PATH 上的 `ffmpeg`，都沒有就略過；操作視窗在 Linux（X11）上也能開啟，方便截圖檢查版面（debug 版可用環境變數 `SCREENRECORDER_DEV`、`SCREENRECORDER_INPUT`、`SCREENRECORDER_SHOT` 自動開啟畫面、模擬操作並截圖，見 `shell/src/ui/dev.rs`）。

### 建置

```bash
cargo build --release -p screenrecorder-ui
```

產生 `target\release\screenrecorder-ui.exe`（單一 exe；發佈時改名為 `ScreenRecorder.exe`）。exe 的圖示與檔案資訊（版本號）在建置時自動寫入。

### 發佈新版本

1. 修改 `Cargo.toml` 的 `[workspace.package] version`（新功能增加次版號，只修正問題增加修訂號）
2. 在 `CHANGELOG.md` 最上方加上這一版的「新增／變更／修正」
3. 合併到 main：GitHub Actions 發現 `Cargo.toml` 的版本還沒發佈過，就會自動建立 tag（例如 `v1.4.0`）並發佈 Release

GitHub Actions（`.github/workflows/release.yml`）會在 Windows 上檢查格式（rustfmt）與程式碼（clippy）、測試、建置 exe，確認版本與 CHANGELOG 一致，再以 CHANGELOG 該版段落為說明發佈 Release。

- **PR**：每個 PR 都會在 Windows 上測試與建置，建置好的 exe 附在該次執行上，可下載試用
- **其他發佈方式**：推送 `v*` tag，或在 Actions 頁面手動執行（分支選 main）並勾選 publish
- 每次合併到 main 都會測試與建置；版本已經發佈過就不會重複發佈。上次發佈失敗（例如測試沒過）時，合併修正後會自動再發佈

**程式碼簽章（選用）**：沒有簽章的 exe 在其他電腦第一次執行時，SmartScreen 可能顯示「Windows 已保護您的電腦」（按「其他資訊 → 仍要執行」即可）。購買程式碼簽章憑證後，在 repo 的 Settings → Secrets and variables → Actions 新增 `SIGN_CERT_PFX`（.pfx 檔的 base64）與 `SIGN_CERT_PASSWORD`，之後發佈的 exe 就會自動簽章。

## 設計重點

- **ddagrab 優先、gdigrab 備援**：啟動時用 ddagrab 實際抓一張畫面測試；錄影時若 ddagrab 在第一張畫面前就失敗（自動模式），立即改用 gdigrab。
- **延伸螢幕**：ddagrab 一次只能擷取一個輸出，所以「所有螢幕」與跨螢幕的範圍會對每個螢幕各開一個 ddagrab，再用 `xstack` 依 Windows 顯示設定中的位置拼接（大小不同的空白處補黑）。ddagrab 的 `output_idx` 是「某張顯示卡上的第幾個輸出」，因此用 DXGI 列舉並以 `-init_hw_device d3d11va=dda:<adapter>` 指定顯示卡；涵蓋的螢幕接在不同顯示卡上時無法合成，改用 gdigrab 擷取整個範圍。預覽圖也走同一條路徑，確保看到的就是錄到的。
- **聲音**：FFmpeg 在 Windows 只能用 dshow 錄麥克風、錄不到系統聲音，所以兩者都以 WASAPI 自行擷取（統一轉成 48 kHz / 立體聲 / float32），經本機 TCP 送進 FFmpeg。對齊方式：FFmpeg 的 `showinfo` 回報每張畫面的時間，推算畫面時間零點；WASAPI 封包帶有 QPC 時間戳記（與 ddagrab 同一個時鐘），依此補靜音或裁切，長時間錄影也不漂移。沒有播放聲音時 WASAPI 不送資料，會依時鐘補靜音；音訊裝置被拔除或切換時以靜音代替並自動重新連線。實測（avsynctest 閃光 + 嗶聲）影音差距約 +12～19 ms，在 1 張畫面以內。
- **分段與防損壞**：分段 MP4 以 fragmented MP4 寫入（每秒一個 fragment），即使 FFmpeg 被強制結束或當機，通常只損失最後一兩秒（每秒寫入一次，加上編碼器還沒送出的畫面；只錄聲音時每秒只有 5 張，x264 改用 `-tune zerolatency` 不預讀）；停止後以 `-c copy` 合併為一般 MP4（`+faststart`）並驗證成品。
- **自動續錄**：錄到一半 FFmpeg 意外結束（例如鎖定畫面、UAC 安全桌面讓 Desktop Duplication 中斷），會保留已錄分段並以退避重試開新分段；超過 15 秒沒有新畫面也會重新啟動 FFmpeg。
- **編碼器（CPU / GPU）**：預設「自動」——有 Intel 顯示卡編碼（QSV）時優先用它（CPU 負擔最小，擷取也在 Intel 顯示卡上時畫面全程留在顯示卡）；沒有時平常用 libx264（畫質最穩、相容性最好），畫面量超過 1080p60（例如 4K、雙螢幕拼接）時改用 GPU 編碼；錄影中偵測到電腦處理不及，會記住並在之後的錄影自動改用 GPU（「更多 → 編碼器」可重設）（同一段錄影不中途切換，否則分段無法無損合併）。GPU 編碼器在啟動時實際試編一小段，只列出真的能用的（例如 MX150 沒有 NVENC 會被排除）；GPU 編碼一開始就失敗時自動退回 CPU。加速匯出與剪輯屬於離線轉檔，固定用 libx264 以畫質為優先。
- **效能監看**：以近 5 秒實際寫入張數與 `dup_frames` 計算實際 fps（FFmpeg 的 `speed=` 會把啟動時間算進去，開頭會嚴重偏低，不適合用來判斷）。
- **加速匯出**：`setpts=PTS/倍率,fps=原fps`，直接捨棄多餘的影格而不做混合，螢幕文字才不會有殘影；聲音用串接的 `atempo`（每段 ≤ 2 倍）變速不變調。
- **剪輯**：`select` / `aselect` 依保留區段逐張挑選並重新接時間戳記，可剪在任意一張畫面上（不受關鍵影格限制），再 `crop` 裁切畫面；因此需要重新編碼。標註在挑選之前疊上（`overlay` / `boxblur`，以 `enable='between(t,…)'` 依原影片時間顯示）：馬賽克與模糊由 FFmpeg 處理，其餘標註畫成透明 PNG 再疊上（與剪輯視窗裡的預覽是同一套繪製，看到的就是輸出的樣子）。圓角、橢圓附上遮罩（`alphamerge`）；框外模糊是整個畫面模糊後，再把框內清楚的畫面疊回去。剪輯視窗的影片由 FFmpeg 解碼（暫停時解單張畫面、播放時連續解碼並跟著聲音的時鐘），馬賽克 / 模糊直接在畫面上處理，不需要瀏覽器或系統解碼器。
- **系統匣**：`Shell_NotifyIcon` / `TrackPopupMenu`。選單開著時會卡住所在執行緒，所以放在獨立的執行緒，錄音與操作視窗不受影響；選單跟隨 Windows 深色 / 淺色模式。
- **單一執行個體**：程式在 `127.0.0.1` 開一個很小的控制端點（只有「顯示視窗」與「結束」），重複啟動時請已在執行的程式把視窗帶到前面；舊版（1.x、2.x）在執行時請它正常收尾結束，再由新版接手。檢查 `Host`（防 DNS rebinding），POST 必須是 JSON 且不接受網頁送來的要求（有 `Origin`）。
- **操作視窗**：egui（OpenGL 繪製），使用 Windows 內建的微軟正黑體；不需要 WebView2，啟動快、程式小。
- **子行程**：程式啟動時把自己放進 kill-on-close 的 Job Object，FFmpeg 等子行程跟著在裡面，本程式被強制結束時 FFmpeg 也會一起結束；播放器等則透過 `explorer.exe` 交給 Shell 啟動，不會被一併關閉。

## 已知限制

- 多個 ddagrab 合成延伸桌面的流程只在單螢幕電腦上以模擬方式驗證過拼接參數；在真正的多螢幕電腦上若合成失敗，自動模式會立即改用 gdigrab。
- 系統聲音會受 Windows 音量影響（音量調得很小時錄到的也很小聲）。
- 錄聲音時，每個分段結尾的畫面會比聲音多約 0.3～0.5 秒（FFmpeg 收到 `q` 後先停止讀取輸入，畫面來源還會多送幾張），因此停止處與暫停點會有一小段沒有聲音；影音同步不受影響。
- gdigrab 在 1080p30 以上較吃 CPU，可能無法維持設定的 fps（會提示）；ddagrab 沒有這個問題。
- 混合 DPI 的多螢幕環境下，gdigrab 的座標換算以 FFmpeg 的行為為準；旋轉的螢幕未實測。
