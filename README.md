# 螢幕錄影（ScreenRecorder）

Windows 11 螢幕錄影工具：**原速錄影並完整保留，停止後再選倍率製作加速版**（可對同一支錄影重複製作不同倍率，高倍率即是縮時影片）。

- 全部以 Rust 撰寫的單一執行檔：錄影、轉檔、剪輯、系統匣與操作視窗（egui）都在同一個程式裡，不需要 WebView2 或瀏覽器
- 擷取與編碼交給 FFmpeg：優先 `ddagrab`（Desktop Duplication，GPU 擷取），不支援或失敗時自動退回 `gdigrab`
- 輸出 H.264 MP4（yuv420p、BT.709）

目前版本：**3.4.1**　各版本的變更見 [CHANGELOG.md](CHANGELOG.md)（版本號顯示在操作視窗的標題列；在程式裡可從「設定 → 關於」或系統匣選單「關於」查看這一版與所有版本的更新說明）。

## 功能

| 項目 | 說明 |
| --- | --- |
| 整支加速 | 剪輯視窗「修剪」分頁「整支加速」1.25×～16×：每段的倍率乘上去（局部加速、放慢一起變快，定格不變），存檔時一次輸出。選「保留聲音」時原速的片段用 `atempo`（每個最多 2 倍，接起來）讓聲音變快、音調不變；局部變速、定格的地方仍然沒有原本的聲音 |
| 手動放大一塊 | 剪輯視窗「畫面」分頁「在播放點框選要放大的地方」：在影片上拖曳框出範圍（維持影片的長寬比），從播放點開始放大 3 秒，開始、結束時間可以再調整。放大的倍率讓框出的範圍剛好填滿畫面（最多 6 倍），開頭、結尾各 0.6 秒平順地拉近、拉遠。輸出時換成剪輯後的時間，用 FFmpeg 的 `zoompan`；和跟著點擊放大一起用時兩個 `zoompan` 接在一起，手動放大的前後不放大點擊，兩種不會同時發生 |
| 字幕樣式 | 「字幕」分頁的「字幕樣式」：大小（1080p 時 32／40／52 像素）、位置（離上緣或下緣 6%）、文字顏色、深色底，改了套用到全部字幕（個別移動過的也放回原位），存在剪輯專案裡 |
| 調整片段順序 | 「修剪」分頁保留兩段以上時的「片段順序」：↑↓ 移動，存的是各片段開頭的時間；之後又刪掉一段、片段被切開時，後半段跟著原本的那一段。順序改了時，輸出改成每段各自剪下來（`trim`，變速時改時間、定格時重複那一張）再 `concat`，聲音一段一段接起來；接縫淡入淡出也算順序改了的地方 |
| 人聲加強 | 「聲音」分頁：`highpass=f=80`、3 kHz 附近提高 3 dB、`acompressor` 壓縮大小聲；分軌錄影時只處理麥克風 |
| 我的樣式 | 標註的顏色與大小按「＋ 存起來」（大小以 1080 高為準，換算到每張圖、每支影片），截圖編輯與剪輯共用，最多 8 個，存在設定裡 |
| 定格、放慢 | 剪輯視窗「修剪」分頁：「在播放點定格」停 1、2、3、5 秒（搭配文字標註解說）；選取一段後「這段放慢」0.5×、0.25×。變速、定格的地方沒有原本的聲音。輸出時挑出保留的畫面、依時間對應換成剪輯後的時間（`setpts`），再用 `fps` 補齊（重複前一張）或丟掉畫面，結尾的定格用 `tpad` 延長；聲音一段一段接起來，變速、定格的地方補上同樣長度的靜音。預覽時放慢的地方慢速播放、定格的地方停住 |
| 旁白 | 剪輯視窗「聲音」分頁「從播放點開始錄旁白」：播放影片（不播原本的聲音），用麥克風邊看邊說，按「停止錄音」存成 WAV（`%LOCALAPPDATA%\ScreenRecorder\voice\`），標在時間軸上；重錄同一段時取代舊的。有旁白時原本的聲音可以「關掉」「調小」（20%）或「不變」，旁白音量 0～200%。預覽播放時一起播旁白 |
| 點擊音效 | 用錄影時記下的點擊（要打開「點擊、按鍵」）在每次點擊加上短短的「喀」一聲，可調音量；輸出時產生一條點擊音效的 WAV 混進聲音 |
| 外部元件 | 「設定 → 外部元件」集中下載 FFmpeg、語音辨識用的 FFmpeg、語音模型：進度、取消、重試、移除；Proxy（跟著系統／不使用／自訂）與測試連線；下載不了時用瀏覽器下載再選擇檔案安裝 |
| 標記要放大的地方 | 錄影中按 `Ctrl+Alt+Z` 記下游標位置（存進標記檔），剪輯「跟著點擊放大」可選「標記的地方」或「每次點擊」 |
| 匯入其他影片 | 拖進視窗或「匯入影片…」：MOV、MKV、AVI、WMV、WebM… 轉成 MP4 存到儲存位置（H.264／HEVC 只換外殼 `-c:v copy`，其他重新壓縮；聲音轉 AAC），MP4 直接複製；清單也列出這些格式，「⋯ → 轉成 MP4」 |
| 滑過就預覽影片 | 最近錄影、全部錄影的縮圖上左右移動滑鼠，旁邊浮出對應時間點的畫面；平均取 12 格（每格用 -ss 跳轉讀一張，hstack 接成一張長條圖），存在縮圖快取 |
| 接縫淡入淡出 | 剪輯「修剪」分頁勾「接縫淡入淡出」：刪掉片段的接縫前後畫面與聲音各淡出、淡入 0.2 秒（FFmpeg fade／afade 加 enable，在剪好的時間上） |
| 錄影中麥克風靜音 | `Ctrl+Alt+U`、錄影面板、控制列或系統匣：麥克風改送靜音（聲音管線照常讀取），靜音時段存進標記檔，剪輯時間軸上標出 |
| 設為封面 | 檢視器上方的圖片圖示（把這一格設為封面）：目前這一格寫進 MP4 當縮圖（attached_pic，只複製串流，修改時間保留）；影片內容不變。檔案總管、多數播放器與程式裡的清單顯示這一格 |
| 通知 Jellyfin 掃描 | 「設定 → 存檔與分享 → 媒體庫（NAS、Jellyfin）」：媒體庫資料夾、Jellyfin 網址與 API 金鑰（一直顯示，還沒選資料夾也能先填、先測試連線）；傳到媒體庫資料夾後 `POST /Library/Refresh`（`core/src/jellyfin.rs`，直接連線不經 Proxy）。之後每 3 秒查一次（最多 1 分鐘）確認 Jellyfin 收到，結果寫「✓ Jellyfin 已收到」；影片資訊的標題、說明、類型、年份、標籤設成 Jellyfin 的 Name、Overview、Genres、ProductionYear、Tags（取回整筆資料換上去再 `POST /Items/{id}`，空的欄位不動；Jellyfin 預設不用影片檔裡的標題）；改了影片資訊、封面、旋轉後換掉媒體庫那一份，請 Jellyfin 重新讀取（不整筆重設）再設一次；有章節時執行「擷取章節圖片」排程工作（媒體庫沒打開這個選項時提醒）；中文字幕傳過去改名為 `同名.zh-TW.srt`。「傳到媒體庫」跳出小視窗，像檔案總管一樣一層層點進媒體庫的資料夾（上面是目前位置，可以回到上一層、在任何一層新增資料夾；從上次用的那一層開始，已經傳過的跳到它在的那一層；`#recycle`、`@eaDir` 等 NAS 系統資料夾不列；檔案庫勾選多支可一起傳），還沒選媒體庫資料夾時按了打開「設定 → 存檔與分享」；錄完自動處理、剪輯和加速版另存好自動傳時放進「自動傳到」選的資料夾（`afterCopySub`，例如 `family/2024`，用同一個視窗選）。檔案庫和主畫面的最近錄影卡片標出媒體庫任何一層裡有同名同大小一份的錄影（綠色標籤「✓ Jellyfin」，沒設定 Jellyfin 時「✓ 媒體庫」，背景讀 NAS 的檔名與大小，2 分鐘重讀一次），篩選可選「還沒傳到媒體庫」；「複製 Jellyfin 連結」複製這支在 Jellyfin 的網址（`/web/#/details?id=…&serverId=…`）。媒體庫（任何一層，NAS 系統資料夾除外）裡同名而且同大小的錄影：重新命名時那一份（連同字幕、加速版）跟著改名，移到資源回收筒時問「兩邊都刪」或「只刪這台電腦的」，之後請 Jellyfin 重新掃描（錄影本來就存在媒體庫資料夾裡時直接重新掃描） |
| 一支錄影的操作 | 主畫面「最近錄影」卡片、「全部錄影」每一列、檢視器上方共用同一份清單（`shell/src/ui/entry_menu.rs`），名稱、圖示、順序都一樣，分成五組：看（播放）、改（剪輯、設為封面、影片資訊、旋轉、重新命名）、做（「製作 ▾」：加速版 / GIF / WebP、壓縮、直式影片、M4A、步驟教學文件、轉成 MP4）、分享（複製檔案、傳到媒體庫、複製 Jellyfin 連結、複製章節、複製操作步驟）、管理（星號、在資料夾中顯示、用 Windows 開啟、移到資源回收筒）。卡片和每一列直接露出播放、剪輯、製作、傳到媒體庫，其他在「⋯」（和按右鍵一樣）；檢視器把這四個以外的照順序排成一排小圖示，資料夾、刪除固定在右上角 |
| 影片資訊 | 檢視器上方的 ⓘ 圖示（影片資訊）：改 MP4 裡的標題、作者、系列、類型、年份、說明、版權（ffmetadata 讀出、`-c copy -map_metadata 0 -map_chapters 0` 寫回，封面與章節保留，修改時間保留） |
| 步驟教學 Word／PowerPoint | 「整理步驟」可選網頁、Word（.docx）、PowerPoint（.pptx）；自己產生 Office Open XML，不需要安裝 Office |
| 比較兩張截圖 | 全部截圖勾兩張按「比較差異」：以 8 像素小格比對，不一樣的地方在較新的那張上用紅框標出，另存成新截圖 |
| 多支錄影一次處理 | 全部錄影勾選後「一次處理…」：剪掉沒動靜的片段、字幕、加速版、壓縮，預設和錄完自動處理一樣（可勾「也存成錄完自動處理的設定」），沿用同一個流程一支一支做 |
| 錄影時勿擾 | 「設定 → 錄影 → 通知」：開始錄影時打開 Windows 的勿擾（只允許鬧鐘），停止後恢復；用系統內部的通知狀態（WNF），當掉時下次開啟會恢復 |
| 錄影時降噪 | 「設定 → 聲音 → 降噪」：錄影時只對麥克風做 FFmpeg afftdn 降噪（聲音管線把系統聲音與麥克風分開送，降噪後再混） |
| 錄影時遮住範圍 | 「設定 → 錄影 → 遮住範圍」：在螢幕上框好的固定範圍錄影時直接打馬賽克（gdigrab、ddagrab；不適用只錄視窗內容） |
| 清掉空白 | 剪輯視窗「修剪」分頁「清掉空白」：勾選「沒動靜」（畫面不動又沒聲音超過 2 秒）、「沒說話」（畫面在動、超過 3 秒沒講話）、「贅字和停頓」（要有字幕）一起找，前兩種標在時間軸上、選刪除或 2×／4×／8× 加速；贅字和停頓：整句只有「嗯、呃、那個」的句子與超過 1 秒的停頓列成清單，勾選後一次剪掉（停頓前後各留 0.25 秒；超過 4 秒的預設不勾） |
| 聲音波形 | 剪輯視窗時間軸下方畫出聲音大小（FFmpeg 解成 4 kHz 單聲道，每 20 毫秒取最大值） |
| 片頭、片尾 | 剪輯視窗「畫面」分頁：標題卡（標題、副標、深色 / 淺色 / 藍色、1～10 秒）淡入淡出接在影片前後，畫成和輸出一樣大；章節與匯出的 SRT 跟著往後移 |
| 只抓文字 | `Ctrl+Alt+T`、「截圖 → 小工具 → 只抓文字…」或系統匣：框選畫面上的一塊，裡面的字直接複製到剪貼簿（Windows 內建的文字辨識）；表格照欄位用 Tab 分隔，可以直接貼到 Excel。框選完滑鼠旁邊馬上顯示「✓ 已複製 N 個字：開頭幾個字」（沒認出字時也會說） |
| 用文字剪影片 | 剪輯視窗「字幕」分頁：按句子旁邊的剪刀剪掉那一句講話的片段（剪掉的可以還原）；Ctrl / Shift＋點時間選好幾句，「剪掉這 N 句」一起剪 |
| 自動命名 | 依字幕、畫面上的字（影片 3 個畫面的文字辨識）、錄影時最常用的程式與視窗標題取名（例如「報價單的填法_10-15」）：重新命名時顯示建議名稱，「設定 → 錄完自動處理 → 命名」可以錄完自動改名（只改預設的 `Rec_時間` 名稱）。改名時字幕檔、`.m4a` 一起改 |
| 英文字幕 | 自動產生字幕時選「翻成英文」或「中英對照」（whisper 的翻譯，FFmpeg 9 以上），英文另存 `同名.en.srt`；「設定 → 錄完自動處理 → 英文字幕」錄完順便做 |
| 外接螢幕 | 自動偵測接上、拔掉螢幕與解析度、排列改變（每 2 秒比對）；記住選的是哪一台實體螢幕，編號變了也錄同一台；錄影中錄的螢幕拔掉或改解析度時馬上停止並存下已錄的部分，只是編號、位置變了就繼續錄；自訂範圍、講稿小視窗不在螢幕上時移回主螢幕 |
| 子資料夾 | 儲存位置（錄影、截圖）底下自己分的子資料夾一併列出（最多 3 層；不列 `.parts`、`markers` 與系統資料夾），清單與縮圖標出在哪個子資料夾，全部截圖「用點的找」可以依資料夾篩選；搜尋、月曆、清理、找相似也包含子資料夾。「設定 → 存檔與分享 → 清單」可以關掉 |
| 第一次使用教學 | 第一次安裝時畫面變暗、只亮出要按的地方，一步一步帶著錄第一部影片（選範圍 → 聲音 → 開始錄影 → 在最近錄影播放、剪輯 → 截圖）；選範圍、開始與停止錄影要真的做，做完自動到下一步。看到一半關掉程式，下次問要不要接著看；隨時可按「跳過教學」或 Esc。剪輯視窗、截圖編輯、全部截圖第一次打開時各有 3 步小提示（新安裝或重新看過教學後才有）。「設定 → 關於 → 重新看教學」可以再看一次 |
| 擷取範圍 | 單一螢幕（DXGI 列舉；可在預覽上拖曳框選只錄其中一部分，按「整個螢幕」取消）、所有螢幕（整個延伸桌面拼成一個畫面），或自訂範圍：按「在螢幕上框選…」直接在螢幕上框（和框選截圖一樣，可調整後按 Enter）、在預覽圖上拖曳框選（可跨螢幕；框好後可拖曳移動、拉邊角調整大小），或展開「精確數值」用 − ＋ 調整 X、Y、寬、高 |
| 聲音 | 可選擇錄「系統聲音」（電腦播放的聲音）與「麥克風」（可選裝置），兩者可同時錄並混音；AAC 48 kHz 立體聲；預設兩者都錄 |
| 錄影設定 | FPS（15/24/30/60 或自訂 1–60）、解析度縮放 100/75/50/25%、是否錄進游標、最長錄影時間（0 = 不限）；全部集中在「設定」視窗（一般、錄影、聲音、截圖、存檔與分享、錄完自動處理、快速鍵、進階、外部元件、關於），主畫面下方只顯示摘要，點一下開到對應分頁 |
| 錄影控制 | 開始 / 暫停 / 繼續 / 停止；暫停採分段錄製，停止後以 concat（stream copy）合併成單一檔案 |
| 主畫面 | 左邊選範圍、看即時預覽；右邊待命時只有聲音、「開始錄影」（按鈕上寫快速鍵）、「框選截圖」「截取錄影範圍」與截圖的快速鍵一行；計時器、影片長度、檔案大小等數據開始錄影才出現。不常用的回溯錄影、排程錄影、講稿小視窗、設定組合收在右上角「更多工具 ▾」。下方「最近錄影」右邊是「檔案庫：錄影｜截圖」，點哪個直接開那一頁。常用操作（播放、剪輯、製作、傳到媒體庫、資料夾、檢視器的左轉右轉）都是一按就到 |
| 截圖 | 主畫面「框選截圖」（`Ctrl+Alt+A`；放開滑鼠後可以調整範圍，再選完成、編輯、複製、釘在桌面或整個螢幕）或「截取錄影範圍」（`Ctrl+Alt+S`，擷取與錄影相同的範圍：單一螢幕 / 所有螢幕 / 自訂範圍），也可從系統匣選單；存成原尺寸 PNG 並複製到剪貼簿（可直接貼到 LINE、Word、信件），存在截圖資料夾（預設是「圖片 → 螢幕擷取畫面」，和錄影分開）；操作視窗擋到範圍時先縮小再截。延遲截圖在畫面上倒數（Esc 取消）。主畫面「檔案庫 → 截圖」以縮圖格瀏覽（縮圖可選小 / 中 / 大，或按住 Ctrl 轉滾輪；可檢視、顯示、改名、勾選多張刪除；從空白處或檔名按住左鍵拖曳框選（按住 Ctrl 是加選）；Ctrl＋點一下多選、Shift＋點一下選一段、Ctrl+A 全選本頁、再按一次選取全部；勾選後可「選取全部 N 張」（搭配搜尋，例如「7/27」）、「只看已選取」，換頁時勾選會保留），與錄影分開。依日期分組，日期旁的勾選框一次選一整天。搜尋也會找圖裡的字（在背景用 Windows 內建的文字辨識讀出每張截圖的字，存在 `ocr_index.json`；找到的縮圖左下角有「字」）。左邊的「用點的找」不用記得關鍵字：依截圖時在用的程式（截圖時記下程式與視窗標題，存在 `shot_meta.json`）、內容類型（錯誤訊息、網頁、對話、表格、程式碼、金額與訂單、文件、含個資…）、圖裡常出現的詞、日期與時段、主要顏色、長截圖／編輯過／有星號，點幾下縮小範圍，每個選項旁顯示張數（內容類型、常見詞、顏色收在「更多分類」，有選的條件時自動打開）。搜尋框打字時列出圖裡真的有的詞與張數，0／O、1／l 容錯，中英對照一起找。「月曆」一個月一頁，看每天的張數與常出現的詞，點一天列出那天的截圖。檢視截圖時下方列出相關的截圖（同一個程式、時間接近、內容相近、長得像）。「整理」選單：「清理舊截圖」把超過一週 / 一個月 / 三個月 / 半年 / 一年的截圖移到資源回收筒；「找出相似的截圖」用縮圖的長相指紋（存在 `shot_hashes.json`）把完全一樣、幾乎一樣或相似的排成一組，預設每組留最新的一張，點縮圖切換保留或刪除。縮圖可以直接拖到其他程式（LINE、Teams、Word、瀏覽器、檔案總管；勾選的一起拖，只給複製） |
| 框選截圖 | `Ctrl+Alt+A` 或系統匣「截圖 → 框選範圍或視窗」：畫面先凍結並變暗，拖曳框選範圍，或點一下擷取游標下的視窗（Esc / 右鍵取消）；從凍結的畫面裁切，截到的就是當下看到的樣子。系統匣另有「全螢幕」（各螢幕 / 所有螢幕）、「固定範圍」（主畫面的錄影範圍）、「重複上次框選」。錄影也能這樣選：系統匣「錄製其他範圍 → 框選範圍或視窗…」框好就開始錄影，另有「全螢幕」與「重複上次框選」。錄自訂範圍時，螢幕上的範圍外圍會一直顯示細框（錄影中紅色、暫停橘色；不會錄進影片，滑鼠可穿過），左上方的小控制列顯示已錄時間，可暫停 / 繼續、停止；拖曳控制列可移動範圍（大小不變，錄影中移動會換一個分段，中間約 0.5～1 秒沒錄到；主畫面的範圍也跟著記住新位置）。控制列右邊的「‹」縮成只有狀態點與停止的小控制列（「›」展開，會記住）；設定 → 錄影 →「錄影控制列」也可以選不顯示（倒數完就隱藏，用快速鍵或系統匣停止）。錄整個螢幕時控制列在螢幕上方中間，可以拖到別的地方（例如另一個螢幕），會記住位置，雙擊放回上方中間 |
| 全域快速鍵 | `Ctrl+Alt+R` 開始 / 停止（倒數中為取消）、`Ctrl+Alt+P` 暫停 / 繼續、`Ctrl+Alt+S` 截圖、`Ctrl+Alt+A` 框選截圖、`Ctrl+Alt+M` 錄影中加標記、`Ctrl+Alt+D` 螢幕畫筆、`Ctrl+Alt+B` 回溯錄影（開始 / 存下）、`Ctrl+Alt+U` 錄影中麥克風靜音 / 取消靜音、`Ctrl+Alt+Z` 錄影中標記要放大的地方、`Ctrl+Alt+T` 只抓文字，在任何程式中都能用（需系統匣常駐）；可在「設定 → 快速鍵」點按鍵後按下新的組合鍵更換（要包含 Ctrl 或 Alt），也可個別停用或還原預設 |
| 倒數與自動縮小 | 開始前倒數 0 / 3 / 5 / 10 秒（操作視窗在錄影範圍外時只在按鈕上倒數，不擋畫面）；開始擷取時自動縮小擋到錄影範圍的操作視窗、停止後還原，避免錄到它（視窗在其他螢幕上就不縮小） |
| 磁碟空間 | 剩餘不到 1 GB 不開始；錄影中低於 2 GB 提醒、低於 512 MB 自動停止並儲存 |
| 正常收尾 | 停止、暫停、結束程式時都對 FFmpeg 送出 `q`，逾時（10 秒）才強制終止 |
| 搜尋說過的話 | 「全部錄影」的搜尋也找影片旁邊的字幕檔（同名的 `.srt`，自動字幕或錄完自動處理產生），符合的錄影底下列出最多 3 句（時間與那一句，搜尋的字標示出來），點一下在檢視器從那一句開始播放 |
| 直式影片（9:16） | 剪輯視窗「畫面裁切」分頁選「放在中間」（整個畫面放在 1080×1920 或 720×1280 的直式畫面中間，上下是放大、模糊、稍暗的同一個畫面，什麼都不會被裁掉）或「跟著游標」（裁出 9:16 的一塊，像攝影機一樣跟著錄影時記下的游標左右移動；游標在鏡頭中間一半的範圍內移動時鏡頭不動，出了範圍才用彈簧平順地移過去；沒有游標位置時跟著點擊；太大時縮成 1080×1920）。預覽時看得到裁切的框。跟著游標用 `sendcmd` 依原影片的時間移動 `crop`；直式影片時不能同時用跟著點擊放大、背景與圓角 |
| 平滑、放大的游標 | 錄影時記下游標的位置（約每 30 毫秒，存在 `markers/`）。剪輯視窗「畫面裁切」分頁打開「換成大游標、平順移動」並選 1.5×／2×／3×：輸出時把游標畫成大的白色箭頭，位置像彈簧一樣平順地跟過去（臨界阻尼，約 0.1 秒追上；手抖、急停、跳動都變得流暢），畫在標註底下，預覽也看得到。FFmpeg 用 `sendcmd` 依原影片的時間移動 `overlay`。勾「停著不動時隱藏」時，停住超過 1.5 秒就把游標移到畫面外，一動就回來。錄影前到「設定 → 錄影」關掉「滑鼠游標：錄進影片」，影片裡才不會同時有原本的小游標 |
| 回溯錄影 | 錄影面板右上角「更多工具 → 回溯錄影」選保留最近 30 秒～10 分鐘後開始（或按 `Ctrl+Alt+B`）：在背景一直錄、只留最近那一段，發生想留下的事時按「存下最近 N 分鐘」（或再按一次 `Ctrl+Alt+B`、系統匣、螢幕上控制列的存下按鈕），存成 `Replay_<時間>.mp4`，可以存好幾次。FFmpeg 用 segment 輸出每 10 秒換一個暫存檔（每秒寫入），定期刪掉太舊的，存下時把最近幾個接起來（不重新壓縮，連正在寫的也包含）；停止時暫存檔全部刪掉（還有沒存下的內容時，主畫面、系統匣、控制列、快速鍵的停止都會先問要不要存下）。用目前的範圍與聲音設定，不倒數、不縮小視窗，不能暫停或加標記 |
| 只錄某個程式的聲音 | 「設定 → 聲音 → 系統聲音來源」選開啟中的程式（列出有視窗的程式，例如 `chrome.exe`、`Teams.exe`）：系統聲音只錄那個程式和它開的子程序播放的聲音（Windows 的 process loopback），其他程式的通知音、音樂不會錄進去；開始錄影時程式沒開或 Windows 版本太舊（不支援）時改錄全部系統聲音，事件紀錄寫上原因。設定組合也會記住 |

| 講稿小視窗 | 錄影面板右上角「更多工具 → 講稿小視窗」：浮在最上層的小視窗，設成不會被錄進影片或截圖（Windows 10 2004 以後）。「編輯」貼上講稿（存在 `%LOCALAPPDATA%\ScreenRecorder\notes.txt`）；「提詞」用深色底大字往上捲，讀的位置固定在上方三分之一，讀過的變暗；空白鍵播放 / 暫停、Home 回到開頭、↑↓ 調速度、滾輪手動調整；「⋯」可調字級、不透明度，預設開始錄影時自動捲動、暫停或停止時停下。操作視窗收到系統匣時一起收起來 |

剪輯視窗：時間軸上有縮圖，拖曳兩端的黃色把手剪掉頭尾，在時間軸上拖過一段可選取並刪除（刪掉的片段點 × 還原），「預覽結果」只播放保留的部分。在時間軸上轉滾輪放大 / 縮小（Shift 左右移動），在影片上轉滾輪逐張前後移動，拖曳上方的黃色橫條整段移動保留範圍。右側「標註」分頁選工具後在影片上點一下或拖曳放置；每個標註在時間軸下方的標註軌有一條，拖曳可調整出現時間（落在刪除片段裡的會提醒），步驟編號依出現時間自動排序，可連續點擊放置；馬賽克、模糊可選方形、圓角、橢圓，也可以改成框外模糊（框內清楚）。標註可以旋轉：拖曳選取框上方的圓點，或在右側調整「角度」。剪輯版之後還能再修改：再次開啟剪輯版時會從原始影片載入當時的剪輯與標註（記在 `%LOCALAPPDATA%\ScreenRecorder\edits\`），儲存時取代那個剪輯版；原始影片被刪除後就只能在剪輯版上繼續剪。時間軸上方有時間尺規（點一下或拖曳移動播放位置）；在縮圖上點一下跳到那裡，拖曳就是選取一段；「分割（S）」把影片切開，點一段就能選取、刪除或加速。播放時預設跳過刪掉的片段（時間軸下方的眼睛圖示可以改成照原樣播）。時間軸下方只有一排：播放、預覽結果、−1 秒、上一格、下一格、+1 秒、分割、＋ 標記、擷取這一格、顯示刪掉的部分、時間、快速鍵。右側分頁：修剪（三步驟說明、清掉空白）｜加速｜畫面｜標註｜字幕（含章節）｜聲音。輸出失敗或取消時可以「回到剪輯」；剪輯中每 10 秒自動存草稿，下次開啟同一支影片可以繼續。快速鍵（按鍵盤圖示看全部）：空白鍵 播放 / 暫停、← / → 上一格 / 下一格（加 Shift 為一秒）、S 分割、M 加標記、Shift+M / Ctrl+Shift+M 下一個 / 上一個標記、I 設為開頭、O 設為結尾、Delete 刪除最後選取的片段或標註、Ctrl+S 儲存、Ctrl+Z / Ctrl+Y 復原 / 重做、Esc 取消選取（沒有選取時關閉剪輯視窗，有還沒儲存的修改會問「儲存後關閉／不儲存／取消」）。

## 使用

### 系統匣常駐

程式啟動後常駐在工作列右下角的系統匣（Windows 11 新程式預設在 `^` 收合區，可拖到工作列上，或在「設定 → 個人化 → 工作列 → 其他系統匣圖示」開啟）。

- **左鍵點圖示**：開啟操作視窗
- **右鍵選單**：開始錄影（沿用上次設定）、錄製指定螢幕 / 所有螢幕、暫停 / 繼續、停止並儲存、加標記、截圖（框選範圍或視窗 / 延遲框選 / 全螢幕 / 固定範圍 / 重複上次框選 / 編輯上次截圖）、切換系統聲音 / 麥克風、開啟儲存資料夾、播放最近的錄影、開機時自動啟動、結束
- 圖示顏色代表狀態：深色 = 待命、紅色圓環 = 倒數中、紅色 = 錄影中、琥珀色 = 已暫停；滑鼠停在圖示上會顯示已錄時間
- 錄影儲存後會跳出通知，點通知開啟操作視窗
- 關閉操作視窗不會結束程式（仍常駐在系統匣）；要結束請用系統匣選單的「結束」
- 設定存在 `%LOCALAPPDATA%\ScreenRecorder\settings.json`，記錄檔 `ScreenRecorder.log` 也在同一處

### 執行編譯好的版本

從 [Releases](https://github.com/omni624562/ScreenRecord/releases/latest) 下載 `ScreenRecorder.zip`（解壓縮後使用）或 `ScreenRecorder.exe`（單一執行檔）。

```
ScreenRecorder.exe
ffmpeg.exe          ← 放在同一個資料夾
```

找不到 `ffmpeg.exe` 時，主畫面上方會出現提示，按「下載並開始使用」即可：從 [gyan.dev](https://www.gyan.dev/ffmpeg/builds/) 下載固定版本 FFmpeg 9.0.2 essentials（約 110 MB，失敗時改用 GitHub 上的同一檔案），比對程式內建的 SHA-256（不是從下載網站取得，檔案遭竄改也會被擋下）後，用 Windows 內建的 `System32\tar.exe` 解出 `ffmpeg.exe`，放到 exe 旁邊（沒有寫入權限時放 `%LOCALAPPDATA%\ScreenRecorder`），完成後自動偵測，不用重開程式。下載可取消，不會留下未完成的檔案。無法下載時，到「設定 → 外部元件」設定 Proxy，或按「用瀏覽器下載」自行下載後按「選擇已下載的檔案…」（zip 或 ffmpeg.exe 都可以），也可以自己放好再按「重新偵測」。  
搜尋順序：`exe 所在資料夾\ffmpeg.exe` → `ffmpeg\bin\ffmpeg.exe` → `bin\ffmpeg.exe` → `%LOCALAPPDATA%\ScreenRecorder\ffmpeg.exe` → `PATH`。

外部元件（FFmpeg、mpv 播放元件 `libmpv-2.dll`、`whisper` 資料夾裡的語音辨識 FFmpeg 與語音模型）都以 exe 所在資料夾為主，整個資料夾帶著走也能用；只有那裡不能寫入時（例如放在 Program Files）才放到 `%LOCALAPPDATA%\ScreenRecorder`。以前放在 `%LOCALAPPDATA%\ScreenRecorder` 的元件，exe 所在資料夾能寫入時，啟動時會自動搬過去（那裡已經有同樣的檔案時，刪掉用不到的那份）。

自動字幕需要有 whisper（語音辨識）的 FFmpeg，essentials 沒有。在「設定 → 外部元件」下載同一版的 FFmpeg 9.0.2 full（約 258 MB，從 GitHub 下載，失敗時改用 gyan.dev，一樣比對內建的 SHA-256）與語音模型（標準 base 約 150 MB、精準 small 約 490 MB、最精準 large-v3-turbo 壓縮版約 570 MB；最精準的中文最準但不能翻成英文，翻譯時改用精準或標準），放在 `ScreenRecorder.exe` 旁邊的 `whisper` 資料夾（那裡不能寫入時，例如放在 Program Files，改放 `%LOCALAPPDATA%\ScreenRecorder\whisper`；找的時候也是先找 exe 旁邊，整個資料夾帶著走也能用），只用來辨識語音；錄影、轉檔仍用原本的 FFmpeg。目前用的 FFmpeg 已經有 whisper 時不用下載。剪輯視窗、錄完自動處理不會自己下載：缺少時剪輯視窗會請你到外部元件下載，錄完自動處理則跳過字幕這一步。

下載外部元件都集中在「設定 → 外部元件」：可以下載、取消、重試、移除，Proxy 可選「跟著系統」（環境變數 `HTTPS_PROXY` 或 Windows 手動設定的 Proxy）、「不使用」或自訂，並可「測試連線」。下載不了時按「用瀏覽器下載」，在瀏覽器或另一台電腦下載後按「選擇已下載的檔案…」：FFmpeg 可選 zip 或 ffmpeg.exe（確認能執行；語音辨識用的要有 whisper），語音模型選 `.bin`（檢查檔頭與大小）。

從系統匣選單「結束」會先把錄影正常收尾並合併再結束。程式不顯示主控台視窗，訊息寫在記錄檔 `%LOCALAPPDATA%\ScreenRecorder\ScreenRecorder.log`。

參數：`--port <n>`（單一執行個體控制用的本機連接埠，預設 47391，被占用時往後找）、`--no-open`（不自動開操作視窗）、`--tray`（只常駐系統匣，開機自動啟動時使用；系統匣還沒準備好時在背景重試、不開視窗，操作視窗等第一次開啟時才建立；開機自動啟動指向別的位置的程式時，例如舊版留在原本的資料夾，啟動時會改成目前這個程式）、`--no-tray`（開發測試用：不建立系統匣、不檢查是否已在執行，可與正式程式並存）。同時只會有一個執行個體，重複啟動會直接開啟現有的操作視窗。

### 發佈新版本

1. 修改 `Cargo.toml` 的 `[workspace.package] version`（新功能增加次版號，只修正問題增加修訂號）
2. 在 `CHANGELOG.md` 最上方加上這一版的「新增／變更／修正」
3. 合併到 main：GitHub Actions 發現 `Cargo.toml` 的版本還沒發佈過，就會自動建立 tag（例如 `v1.4.0`）並發佈 Release

GitHub Actions（`.github/workflows/release.yml`）會在 Windows 上檢查格式（rustfmt）與程式碼（clippy）、測試、建置 exe，確認版本與 CHANGELOG 一致，再以 CHANGELOG 該版段落為說明發佈 Release。

- **PR**：每個 PR 都會在 Windows 上測試與建置，建置好的 exe 附在該次執行上，可下載試用
- **其他發佈方式**：推送 `v*` tag，或在 Actions 頁面手動執行（分支選 main）並勾選 publish
- 每次合併到 main 都會測試與建置；版本已經發佈過就不會重複發佈。上次發佈失敗（例如測試沒過）時，合併修正後會自動再發佈

**程式碼簽章（選用）**：沒有簽章的 exe 在其他電腦第一次執行時，SmartScreen 可能顯示「Windows 已保護您的電腦」（按「其他資訊 → 仍要執行」即可）。購買程式碼簽章憑證後，在 repo 的 Settings → Secrets and variables → Actions 新增 `SIGN_CERT_PFX`（.pfx 檔的 base64）與 `SIGN_CERT_PASSWORD`，之後發佈的 exe 就會自動簽章。

## 設計重點

- **ddagrab 優先、gdigrab 備援**：啟動時用 ddagrab 實際抓一張畫面測試；錄影時若 ddagrab 在第一張畫面前就失敗（自動模式），立即改用 gdigrab。
- **延伸螢幕**：ddagrab 一次只能擷取一個輸出，所以「所有螢幕」與跨螢幕的範圍會對每個螢幕各開一個 ddagrab，再用 `xstack` 依 Windows 顯示設定中的位置拼接（大小不同的空白處補黑）。ddagrab 的 `output_idx` 是「某張顯示卡上的第幾個輸出」，因此用 DXGI 列舉並以 `-init_hw_device d3d11va=dda:<adapter>` 指定顯示卡；涵蓋的螢幕接在不同顯示卡上時無法合成，改用 gdigrab 擷取整個範圍。預覽圖也走同一條路徑，確保看到的就是錄到的。
- **聲音**：FFmpeg 在 Windows 只能用 dshow 錄麥克風、錄不到系統聲音，所以兩者都以 WASAPI 自行擷取（統一轉成 48 kHz / 立體聲 / float32），經本機 TCP 送進 FFmpeg。對齊方式：FFmpeg 的 `showinfo` 回報每張畫面的時間，推算畫面時間零點；WASAPI 封包帶有 QPC 時間戳記（與 ddagrab 同一個時鐘），依此補靜音或裁切，長時間錄影也不漂移。沒有播放聲音時 WASAPI 不送資料，會依時鐘補靜音；音訊裝置被拔除或切換時以靜音代替並自動重新連線。實測（avsynctest 閃光 + 嗶聲）影音差距約 +12～19 ms，在 1 張畫面以內。
- **分段與防損壞**：分段 MP4 以 fragmented MP4 寫入（每秒一個 fragment），即使 FFmpeg 被強制結束或當機，通常只損失最後一兩秒（每秒寫入一次，加上編碼器還沒送出的畫面；只錄聲音時每秒只有 5 張，x264 改用 `-tune zerolatency` 不預讀）；停止後以 `-c copy` 合併為一般 MP4（`+faststart`）並驗證成品。
- **自動續錄**：錄到一半 FFmpeg 意外結束（例如鎖定畫面、UAC 安全桌面讓 Desktop Duplication 中斷），會保留已錄分段並以退避重試開新分段；超過 15 秒沒有新畫面也會重新啟動 FFmpeg。
- **編碼器（CPU / GPU）**：預設「自動」——有 Intel 顯示卡編碼（QSV）時優先用它（CPU 負擔最小，擷取也在 Intel 顯示卡上時畫面全程留在顯示卡）；沒有時平常用 libx264（畫質最穩、相容性最好），畫面量超過 1080p60（例如 4K、雙螢幕拼接）時改用 GPU 編碼；錄影中偵測到電腦處理不及，會記住並在之後的錄影自動改用 GPU（「更多 → 編碼器」可重設）（同一段錄影不中途切換，否則分段無法無損合併）。GPU 編碼器在啟動時實際試編一小段，只列出真的能用的（例如 MX150 沒有 NVENC 會被排除）；GPU 編碼一開始就失敗時自動退回 CPU。加速匯出與剪輯屬於離線轉檔，固定用 libx264 以畫質為優先。
- **效能監看**：以近 5 秒實際寫入張數與 `dup_frames` 計算實際 fps（FFmpeg 的 `speed=` 會把啟動時間算進去，開頭會嚴重偏低，不適合用來判斷）。
- **加速匯出**：`setpts=PTS/倍率,fps=原fps`，直接捨棄多餘的影格而不做混合，螢幕文字才不會有殘影；聲音用串接的 `atempo`（每段 ≤ 2 倍）變速不變調。
- **剪輯**：`select` / `aselect` 依保留區段逐張挑選並重新接時間戳記，可剪在任意一張畫面上（不受關鍵影格限制），再 `crop` 裁切畫面；因此需要重新編碼。標註在挑選之前疊上（`overlay` / `boxblur`，以 `enable='between(t,…)'` 依原影片時間顯示）：馬賽克與模糊由 FFmpeg 處理，其餘標註畫成透明 PNG 再疊上（與剪輯視窗裡的預覽是同一套繪製，看到的就是輸出的樣子）。圓角、橢圓附上遮罩（`alphamerge`）；框外模糊是整個畫面模糊後，再把框內清楚的畫面疊回去。剪輯視窗的影片由 FFmpeg 解碼（暫停時解單張畫面、播放時連續解碼並跟著聲音的時鐘），馬賽克 / 模糊直接在畫面上處理，不需要瀏覽器或系統解碼器。
- **系統匣**：`Shell_NotifyIcon` / `TrackPopupMenu`。選單開著時會卡住所在執行緒，所以放在獨立的執行緒，錄音與操作視窗不受影響；選單跟隨 Windows 深色 / 淺色模式。
- **單一執行個體**：程式在 `127.0.0.1` 開一個很小的控制端點（只有「顯示視窗」與「結束」），重複啟動時請已在執行的程式把視窗帶到前面；舊版（1.x、2.x）在執行時請它正常收尾結束，再由新版接手。檢查 `Host`（防 DNS rebinding），POST 必須是 JSON 且不接受網頁送來的要求（有 `Origin`）。
- **操作視窗**：egui（OpenGL 繪製），使用 Windows 內建的微軟正黑體；不需要 WebView2，啟動快、程式小。
- **子行程**：程式啟動時把自己放進 kill-on-close 的 Job Object，FFmpeg 等子行程跟著在裡面，本程式被強制結束時 FFmpeg 也會一起結束；播放器等則透過 `explorer.exe` 交給 Shell 啟動，不會被一併關閉。

## 已知限制

- 多個 ddagrab 合成延伸桌面的流程只在單螢幕電腦上以模擬方式驗證過拼接參數；在真正的多螢幕電腦上若合成失敗，自動模式會立即改用 gdigrab。
- 系統聲音會受 Windows 音量影響（音量調得很小時錄到的也很小聲）。
- 錄聲音時，每個分段結尾的畫面會比聲音多約 0.3～0.5 秒（FFmpeg 收到 `q` 後先停止讀取輸入，畫面來源還會多送幾張），因此停止處與暫停點會有一小段沒有聲音；影音同步不受影響。
- gdigrab 在 1080p30 以上較吃 CPU，可能無法維持設定的 fps（會提示）；ddagrab 沒有這個問題。
- 混合 DPI 的多螢幕環境下，gdigrab 的座標換算以 FFmpeg 的行為為準；旋轉的螢幕未實測。
